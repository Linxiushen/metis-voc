# 数据源、处理与价值

## 按决策需求选数据

| 数据 | 支撑的问题 | 推荐接入 | 处理与限制 |
| --- | --- | --- | --- |
| 商品、价格、类目、排名时间序列 | 竞争密度、价格带、趋势、季节性 | KeepaMore 导入/API；Keepa 需另写适配器 | 市场/币种归一化、按商品去重；排名不是销量 |
| 授权评论正文及时间、星级 | 痛点、购买动机、退货原因、JTBD | 有许可的评论 API 或自有数据导入 | 去重、脱敏、翻译与主题标注；评分总量不是正文样本 |
| 自有订单、广告、库存、退货 | 单位经济、需求验证、复盘 | SP-API、广告 API、ERP/WMS | 以 SKU/ASIN、市场和日期关联；当前需扩展适配器 |
| BOM、包装、运费、关税、履约 | 贡献利润、可制造性、试产门槛 | 企业授权导入或内部 API | 标明报价日期、税率、假设和区间；公开价格不能替代成本 |
| 搜索需求与广告关键词 | 市场细分、需求趋势、定位 | 有许可的关键词服务 | 区分搜索量、曝光、点击与转化，统一统计周期 |
| 产品图片与设计素材 | 概念方向、场景套图、沟通 | 自有参考图和 Lovart | 来源授权、版本、设计一致性；需人工制造审核 |

先购买能回答当前关键决策的数据，再扩充覆盖。每个来源记录供应商、套餐/额度、市场覆盖、更新频率、可导出/再分发权利、失败行为和成本上限。此文不承诺任何供应商当前价格或免费额度。

## 当前已实现与预留

主应用有 KeepaMore 导出解析、多批数据合并、API 客户端与研究队列集成。网页免费导出导入器当前严格限定 Amazon US、USD、cat bed 的 CSV/XLSX；其他场景需扩展适配器。免费网页会员和 API 套餐是不同产品；能登录网页不代表有免费 API 权限。分页只能在服务商正常限额内增加覆盖，不绕过权限、验证码或限流。

DeepSeek/Qwen 为分析模型接入，不是原始市场数据库。Lovart 为概念图服务接入，实际能力取决于账号和接口权限。Keepa、SP-API、DataForSEO 在 `research-kit` 中只有原型接口，不能声称已全部接通。

## 数据链路

1. 保留原始授权导出及采集批次、URL/商品 ID、时间和市场。
2. 解析字段，统一价格、币种、尺寸、单位和日期；拒绝损坏数据。
3. 按稳定标识去重；统计有效商品数、有效评论正文数及缺失比例。
4. 区分观测值、第三方估算、模型推断、内部假设和合成样例。
5. 将分析结果映射到报告契约，并保留来源 ID 和证据不足的模块。
6. 人工审核关键结论，记录报告版本和决策依据；复盘时导入真实经营结果。

## 开源样例

VOC 样例已重写为原创合成文本，使用示例域名，公开评分/评论总体数为零。定义见 `data/SYNTHETIC_DATA_DICTIONARY.md`。参考报告还保留部分历史公开市场事实/链接以说明来源格式；本次发布未重新采集它们，不能视为当前行情或经过独立核验的实证报告。

随附产品 SVG 是原创版式示意。原运营站的公司资料、账号、原始评论数据和概念图未再分发。外部资料即使能公开访问，也不自动授予复制、商业使用或再次公开的权利。

# 开源发布范围

本仓库是从运行项目整理出的独立源码树，使用全新 Git 历史。它包含主应用、前端、Worker、数据库定义、测试、构建脚本、文档、原创合成样例和可选数据管道原型。

## 不在包内

- 原生产数据库、账号/会话、API Key、加密密钥、访问令牌和凭据配置。
- 原公司资料、用户研究报告、第三方评论正文数据集和未确认再分发权利的概念图。
- 原 Git 历史、部署输出、访问日志、备份和运营工单。
- node_modules、构建 bundle、Python 缓存、运行状态和本地测试数据。
- API 订阅额度、Cloudflare 资源、支付服务和私有飞书权限。

上述内容没有从原工作目录删除；它们不属于公共发行物。原创示意图和合成数据用于保证源码可运行与测试，不代表已验证的商业建议。

## 复现与校验

发行 ZIP 使用 `git archive` 从已提交的发布版本创建；不是把整个工作目录压缩，因此不会包含被忽略的本地密钥和数据库。Release 同时提供 SHA-256 校验和。下载后按 QUICKSTART 安装锁定依赖，执行检查与本地冒烟。

源码适合自部署、学习研究流程、扩展数据源和二次开发。第三方接手时应先跑通无付费依赖的演示链路，再配置自己的数据授权、供应商和生产环境。
